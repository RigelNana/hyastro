# hyastro 产品需求文档

- 文档状态：需求基线草案
- 目标读者：天文软件使用者、天体测量研究者、Rust 库维护者、历表和观测系统集成者
- 产品形态：强类型、上层、可组合的 Rust 天文计算库族
- 规范关键词：必须、不得、应、可以分别对应 RFC 2119 的 MUST、MUST NOT、SHOULD、MAY

## 1. 产品定义

hyastro 以 Hifitime、SOFA 系算法和 ANISE 等经过核验的后端为数值基础，提供统一的强类型接口。产品目标不是逐个翻译底层自由函数，而是把单位、时间尺度、参考系、原点、历元、模型、数据版本和精度边界编码进类型或显式上下文，使常见天文计算能以短而清晰的调用链完成。

核心价值：

1. 在编译期阻止角度/长度、UTC/TT、ICRS/ITRS、点/向量、几何位置/视位置等误用。
2. 把闰秒、EOP、历表、气象数据等易变数据放到显式上下文，不依赖隐藏全局状态。
3. 以深模块封装完整计算链，用户不需要按 SOFA 调用顺序手工拼接数十个步骤。
4. 保留底层模型选择、精度、数据来源和中间量的可审计性。
5. 对常用路径提供零堆分配或低分配实现，并允许批处理和并行查询。
6. 允许替换历表、EOP、闰秒和大气模型适配器，而不改变上层领域类型。

## 2. 用户与关键场景

### 2.1 目标用户

- 天文爱好者：日期、坐标转换、太阳月球和行星位置、升中落、晨昏蒙影、月相、食和掩星。
- 专业观测者：高精度视位置、站心坐标、折射、BJD、恒星时、EOP、望远镜指向。
- 星表工程者：Gaia DR3 解析、历元传播、协方差传播、交叉匹配、视差和径向速度。
- 航天与导航开发者：历表状态、参考系变换、地面站几何、光行时和事件搜索。
- Rust 库作者：可选后端、`no_std` 数学内核、稳定序列化格式和可验证算法。

### 2.2 代表性任务

- 从 `2026-08-05T12:00:00 UTC` 得到 TT、UT1、TDB、ERA、GAST，并返回所用闰秒表和 EOP 记录版本。
- 把 Gaia DR3 的六参数星表记录从 J2016.0 传播到观测时刻，计算某 WGS84 站点的观测方位和折射后高度。
- 从 DE440 BSP 查询月球相对地球的状态，计算视赤经赤纬、月相、照亮比例、天平动和升落时刻。
- 在给定区间搜索太阳食、月食、掩星、合、冲、最大距角和最近角距离，并返回收敛误差与几何分类。
- 把 ITRF 站点状态转换到 GCRS/BCRS，计算 Roemer、Einstein、Shapiro 延迟和 BJD_TDB。

## 3. 范围与优先级

### 3.1 P0：可信基础

- 强类型量、线性代数、球面几何、常数和数值工具。
- 历法、时间尺度、两段式 JD/MJD、闰秒和 EOP。
- IAU 2006/2000A/2000B 地球定向链和 ICRS/BCRS/GCRS/CIRS/TIRS/ITRS。
- 观测者、大地测量、WGS84、基础天体测量修正。
- 统一历表接口与至少一个高精度 DE BSP 后端。
- 权威测试向量、结构化错误和覆盖区间。

### 3.2 P1：可用天文工作流

- Gaia DR3 星表、空间运动和协方差传播。
- VSOP87 后端、太阳/月球/行星表观位置。
- 光学折射、升中落、晨昏蒙影、月相、合冲方照、距角极值。
- BJD/HJD、径向速度改正、天体物理常用派生量。
- 批处理、缓存和 Serde 互操作。

### 3.3 P2：高级和专门域

- 小行星/彗星轨道、MPC 数据、SGP4/TLE、数值轨道传播适配。
- 对流层与电离层延迟、地球潮汐和站点位移。
- 完整日月食、贝塞尔根数、沙罗系列、掩星路径和接触线。
- FITS/VOTable/Parquet、HEALPix、WCS 与大规模星表查询适配。
- 行星定向、天体固连参考系、形状模型和地形地平线。

优先级表示交付顺序，不表示低优先级需求可以用占位实现进入稳定接口。

## 4. 产品原则

### 4.1 强类型优先

- 公开接口不得用裸 `f64` 表达带单位、时间尺度、参考系、原点或语义范围的量。
- “弧度”和“度”是同一角量的输入输出表示；赤经、纬度、方位、时角是不同领域语义，必须由不同类型或受约束包装表示。
- 三维位置和自由向量必须可区分；位置、速度和状态必须带参考系与原点。
- 旋转必须携带源参考系和目标参考系，防止矩阵方向颠倒。
- 日期、瞬间、时长、历元和时间尺度必须分别建模。

### 4.2 显式上下文

所有依赖时变数据或模型选择的计算必须接收不可变上下文。上下文至少可包含：

- 闰秒表；
- EOP 数据和插值策略；
- 历表后端和加载的内核集合；
- 参考系/章动/岁差模型；
- 地球椭球、站点运动和大气模型；
- 精度策略、迭代上限和异常策略；
- 数据来源、版本、发布时间与覆盖区间。

不得在库内部联网、自动更新数据或读取进程级隐式配置。

### 4.3 高层工作流与底层可审计性并存

- 常见流程应由对象方法或工作流对象一次完成，例如 `catalog.place(at, observer, &ctx)`。
- 结果必须可选返回修正分解、中间参考系、迭代次数、数据版本和误差估计。
- 底层标准模型可以公开为专家模块，但不得迫使普通用户手工拼接调用顺序。

### 4.4 模型不能静默混用

- IAU 2006 岁差与 IAU 2000A/2000B 章动的组合必须明确；不得创造“IAU 2006A 章动”这一错误模型名称。
- FK4/B1950 与 FK5/J2000 的转换必须处理 E-terms、历元和自行约定，不得当作静态三维旋转。
- UTC、UT1、TT、TDB 的转换必须报告缺少的闰秒/EOP/历表数据；不得用固定偏移假装完整转换。
- 几何、天体测量、视和观测位置必须标记所含修正，防止重复改正。

## 5. 领域模型与顶层模块

建议的稳定顶层模块：

| 模块 | 责任 | 外部接缝 |
| --- | --- | --- |
| `math` | 强类型量、向量、旋转、球面、数值算法 | 无数据后端 |
| `time` | 瞬间、历法、时间尺度、闰秒、EOP、恒星时 | `LeapSeconds`、`Eop` |
| `frame` | 参考系统、参考架、原点和状态变换 | `Frames`、行星定向适配器 |
| `earth` | 椭球、站点、地理坐标、地球定向链 | EOP、站点运动模型 |
| `astro` | 星表参数、空间运动、视位置和观测位置 | 历表、大气模型 |
| `ephem` | 天体状态与姿态查询 | `Ephemeris`、`Orientation` |
| `event` | 根、极值、接触和事件分类 | 历表、观测模型 |
| `catalog` | 星表记录、解析、协方差和批处理 | 格式适配器 |
| `media` | 光学折射、对流层、电离层、传播延迟 | `Atmosphere`、天气数据 |

设计必须遵循深模块原则：外部接口小，完整模型链和缓存位于实现内部。只有存在至少两个真实实现时才稳定公开适配器接缝。

## 6. 功能需求

## 6.1 强类型数学与物理量

### 6.1.1 角度与角语义

- **MATH-ANG-001** 支持弧度、度、角分、角秒、毫角秒、微角秒、圈和时/分/秒时角的构造、解析、格式化与显式转换。
- **MATH-ANG-002** 支持有符号角、无符号整圈角、经度、纬度、赤经、赤纬、时角、方位角、高度、天顶距、相位角和距角的合法范围。
- **MATH-ANG-003** 支持规范化到 `[0, 2π)`、`(-π, π]`、`[-π/2, π/2]`，并将规范化策略放在语义类型上。
- **MATH-ANG-004** 支持 DMS/HMS 文本解析与格式化、符号、进位、负零和边界值。
- **MATH-ANG-005** 三角函数接收角类型；反三角函数返回角类型；不得在公开接口泄露“默认弧度”的裸数约定。
- **MATH-ANG-006** 支持角速度、角加速度和每儒略年自行单位。
- **MATH-ANG-007** 支持球面角的最短差、定向差、解包裹和跨零连续处理。

### 6.1.2 标量与单位

- **MATH-QTY-001** 支持长度、速度、加速度、时间、频率、质量、温度、压力、湿度、波长和无量纲量。
- **MATH-QTY-002** 天文单位、公里、米、秒、日、儒略年、光秒、秒差距等转换必须使用版本化常数。
- **MATH-QTY-003** 相对湿度必须验证范围；温度必须区分绝对温标；压力和波长必须显式单位。
- **MATH-QTY-004** 核心算法以 `f64` 为规范数值表示；除非有真实算法需求，不把浮点泛型扩散到公开接口。

### 6.1.3 三维向量、点和状态

- **MATH-VEC-001** 支持三维向量的加减、点积、叉积、模、归一化、投影、拒绝分量和夹角。
- **MATH-VEC-002** 支持带长度的位置、带速度的速度向量和位置/速度状态。
- **MATH-VEC-003** 状态必须携带参考系、原点和历元；不同参考系或原点的状态不得直接相加。
- **MATH-VEC-004** 支持批量结构布局和迭代器接口，避免逐项堆分配。
- **MATH-VEC-005** 零向量归一化、非有限分量和退化几何必须返回结构化错误。
- **MATH-VEC-006** 支持球面坐标与笛卡尔位置/方向的双向转换，并处理极点和零距离。

### 6.1.4 矩阵、旋转和四元数

- **MATH-ROT-001** 支持 `3×3` 旋转矩阵的构造、组合、转置/逆、应用和正交性检查。
- **MATH-ROT-002** 支持单位四元数、轴角、欧拉序列和旋转矩阵互转。
- **MATH-ROT-003** 旋转类型必须编码 `From → To` 方向；组合只允许相邻参考系匹配。
- **MATH-ROT-004** 支持 `6×6` 状态变换或等价的旋转加角速度表示，正确变换随时间变化参考系中的速度。
- **MATH-ROT-005** 四元数必须处理双覆盖、规范化、共轭、逆、SLERP 和短弧选择。
- **MATH-ROT-006** 欧拉角必须显式序列、内禀/外禀和奇异性，不提供含糊的默认欧拉角。
- **MATH-ROT-007** 从近似矩阵恢复旋转时必须提供正交化策略和残差。

### 6.1.5 球面几何

- **MATH-SPH-001** 支持大圆角距、位置角、方位、球面三角形边角求解和面积。
- **MATH-SPH-002** 支持大圆交点、球面线段最近点、点到大圆距离、轨迹穿越和包围测试。
- **MATH-SPH-003** 支持球面线性插值、单位向量均值、加权质心和局部切平面基。
- **MATH-SPH-004** 支持圆锥、球冠、经纬矩形和多边形的包含/相交原语。
- **MATH-SPH-005** 所有算法必须稳定处理重合点、对跖点、极点、跨经度零点和极小角距。
- **MATH-SPH-006** 可选支持 HEALPix 索引、邻域、圆锥检索和多分辨率覆盖，放在独立适配模块。

### 6.1.6 常数

- **MATH-CON-001** 提供数学常数、SI 定义常数、IAU 名义太阳/行星常数和常用天文换算常数。
- **MATH-CON-002** 每个常数必须有符号名、值、单位、来源、决议/版本和是否精确定义。
- **MATH-CON-003** 不把历表质量参数、地球定向数据或会更新的观测量伪装成永恒编译期常数。
- **MATH-CON-004** 常数组必须可按标准版本选择，禁止同名静默换值。

### 6.1.7 数值工具

- **MATH-NUM-001** 提供 Horner 多项式、Chebyshev 求值及导数、稳定求和、插值和有限差分原语。
- **MATH-NUM-002** 提供带括区间的 Brent 类求根、二分、割线、Newton 混合策略。
- **MATH-NUM-003** 提供有界一维极值、根去重、周期函数解包裹和扫描括区间。
- **MATH-NUM-004** 提供线性、Hermite、Lagrange、三次样条及 EOP 专用插值策略；不得在闰秒断点跨越错误插值。
- **MATH-NUM-005** 迭代算法必须返回收敛状态、残差、迭代次数和最后括区间。
- **MATH-NUM-006** 容差必须具有物理单位或相对/绝对语义，禁止单一无名 `epsilon` 控制所有域。
- **MATH-NUM-007** 支持协方差的 Jacobian 传播、对称化、正定性检查和蒙特卡洛验证辅助。

## 6.2 时间系统

### 6.2.1 历法与日期

- **TIME-CAL-001** 支持推算公历、推算儒略历及显式的历史切换历法；不得假定全球统一改革日期。
- **TIME-CAL-002** 支持天文年编号和公元纪年显示，明确是否存在第 0 年。
- **TIME-CAL-003** 支持日期合法性、闰年、月长、年内日、ISO 周日期和星期。
- **TIME-CAL-004** 支持负年份和公元前日期；解析格式必须明确年份位数与符号。
- **TIME-CAL-005** 支持日期加减日、月、年；月/年运算必须有月底夹取或报错策略。
- **TIME-CAL-006** 支持 Gregorian/Julian 与日序、JD/MJD/Rata Die 的转换。

### 6.2.2 连续时间表示

- **TIME-REP-001** 支持带尺度的 JD、MJD、两段式 JD、儒略世纪和儒略千年。
- **TIME-REP-002** 两段式表示必须支持 J2000、MJD、日整数加日小数等拆分，算法不得无必要合并成一个 `f64`。
- **TIME-REP-003** 支持儒略纪元与贝塞尔纪元的构造、转换和格式化。
- **TIME-REP-004** 支持 Unix 时间、POSIX 时间、GPS 周/周内秒、GPS 连续秒，并明确滚周与闰秒语义。
- **TIME-REP-005** 支持 ISO 8601/RFC 3339 的可表示子集；UTC 闰秒 `23:59:60` 必须可解析与格式化。
- **TIME-REP-006** 支持纳秒级或更细的固定精度内部时长；任何精度损失必须显式。

### 6.2.3 时间尺度和转换

- **TIME-SCL-001** 支持 UTC、TAI、TT、UT1、TCG、TCB、TDB 和 GPS 时间。
- **TIME-SCL-002** 支持 TT(TAI)、TCG(TT)、TCB(TDB) 的 IAU 线性关系及 TDB−TT 周期项的模型选择。
- **TIME-SCL-003** 高精度 TDB/TCB 转换应允许使用观测者位置和历表；低阶近似必须标注模型与误差范围。
- **TIME-SCL-004** UTC↔TAI 必须使用版本化闰秒表，并处理 1960–1971 的 UTC 漂移段或明确返回不支持错误。
- **TIME-SCL-005** UTC↔UT1 必须使用 EOP 的 UT1−UTC；超覆盖区间不得静默使用 0。
- **TIME-SCL-006** 支持 `TAI−UTC`、`UT1−UTC`、`TT−UT1`（Delta T）查询，并区分观测值、预报值和历史模型值。
- **TIME-SCL-007** 转换图必须选择物理正确路径并避免往返累计误差；结果包含所用数据版本。
- **TIME-SCL-008** 不存在或歧义的 UTC 本地表示必须返回错误；未来闰秒未知必须通过覆盖错误表达。

### 6.2.4 闰秒、EOP 与 Delta T 数据

- **TIME-DAT-001** 闰秒适配器支持内置表、IERS Bulletin C/标准列表解析和用户提供数据。
- **TIME-DAT-002** EOP 适配器支持 IERS finals2000A、Bulletin A/B/C04 类数据。
- **TIME-DAT-003** EOP 至少提供 UT1−UTC、`xp`、`yp`、`dX`、`dY`、LOD；缺测字段不得被默认零掩盖。
- **TIME-DAT-004** 支持 EOP 插值、闰秒边界处理和覆盖检查。
- **TIME-DAT-005** Delta T 支持从 TT−TAI、TAI−UTC、UT1−UTC 精确组合；古代/未来经验模型作为独立可选适配器。
- **TIME-DAT-006** 数据对象不可变、线程安全，并可由调用者原子替换。

### 6.2.5 地球旋转和恒星时

- **TIME-ROT-001** 支持 ERA、GMST、GAST、地方平恒星时、地方视恒星时。
- **TIME-ROT-002** 支持 equation of equinoxes 与 equation of origins，并明确它们连接的量。
- **TIME-ROT-003** 计算必须区分 UT1 输入与 TT 输入，类型阻止互换。
- **TIME-ROT-004** 支持 ERA/恒星时的角速度和时间反解，用于中天事件初值。
- **TIME-ROT-005** 地方恒星时必须明确站点经度符号和参考子午线。

### 6.2.6 时区与民用时间

- **TIME-ZONE-001** 核心库只承诺 UTC 与固定偏移；IANA 时区作为可选适配器。
- **TIME-ZONE-002** 夏令时重复/跳过的本地时间必须要求调用者选择歧义策略。
- **TIME-ZONE-003** 时区转换不得影响天文时间尺度定义。

## 6.3 地球定向、岁差章动与参考系

### 6.3.1 IAU/IERS 模型

- **EOP-MOD-001** 支持 IAU 2006 岁差、IAU 2000A 完整章动和 IAU 2000B 截断章动。
- **EOP-MOD-002** 支持 frame bias、precession-bias、nutation、precession-nutation 矩阵及分量角。
- **EOP-MOD-003** 支持 Fukushima-Williams 角、平均黄赤交角、章动经度/交角。
- **EOP-MOD-004** 支持 CIP `X`/`Y`、CIO locator `s`、TIO locator `s′` 和 celestial pole offsets `dX`/`dY`。
- **EOP-MOD-005** 支持 equinox-based 与 CIO-based 两条等价地球定向链并互相核验。
- **EOP-MOD-006** 支持 ERA、GMST、GAST、equation of equinoxes、equation of origins。
- **EOP-MOD-007** 支持极移 `xp`/`yp`、LOD 和地球自转角速度修正。
- **EOP-MOD-008** 可选支持亚日潮汐 EOP 修正、自由核章动和高频极移模型。

### 6.3.2 天球到地球变换链

- **EOP-XFM-001** 提供 GCRS→CIRS→TIRS→ITRS 及逆向的类型安全变换。
- **EOP-XFM-002** 提供合成的 celestial-to-terrestrial 旋转和分步诊断结果。

## 6.9 补充功能域

以下需求补足原始范围中容易遗漏但会影响上层接口稳定性的领域。

### 6.9.1 不确定度

- **X-UNC-001** 测量结果可以携带标准差或协方差。
- **X-UNC-002** 支持线性协方差传播、数值 Jacobian 和可选采样传播。
- **X-UNC-003** 事件结果支持由输入协方差或多模型差异估计的时刻/路径不确定度。
- **X-UNC-004** 不得把浮点舍入误差、模型误差、数据误差和输入测量误差合并成无解释的单一数值。

### 6.9.2 数据格式和互操作

- **X-IO-001** 支持稳定的文本显示和机器序列化；显示格式与无损交换格式分离。
- **X-IO-002** 可选支持 Serde、FITS、VOTable、ECSV、Parquet、SPICE kernels、IERS 表和 MPC 数据。
- **X-IO-003** 序列化时间必须包含尺度，坐标必须包含参考系、原点、历元和单位。
- **X-IO-004** 支持 `nalgebra` 等线性代数类型的显式转换，但不让第三方类型成为稳定领域接口。
- **X-IO-005** 支持 Python/WASM/FFI 的窄适配层；核心 Rust 类型不因绑定需求退化为裸数组。

### 6.9.3 天区与图像坐标

- **X-WCS-001** 可选支持 FITS WCS 的常见天球投影、像素↔天空坐标和畸变适配。
- **X-WCS-002** 支持视场角、姿态、焦平面、板解参数和切平面投影。
- **X-WCS-003** 星表匹配与 WCS 共享方向/切平面类型，不重复定义坐标语义。

### 6.9.4 星座与传统分类

- **X-SKY-001** 可选支持 IAU 星座边界和星座查询，边界数据版本可追溯。
- **X-SKY-002** 可选支持天体名称、NAIF ID、MPC 编号和常用目录标识解析；名称解析不得依赖隐式网络。

### 6.9.5 性能与平台

- **X-PERF-001** `math` 与不依赖系统时间/文件的算法内核应支持 `no_std`；分配功能通过 `alloc` 特性启用。
- **X-PERF-002** 热路径单点坐标变换和历表多项式求值应做到零堆分配。
- **X-PERF-003** 批处理接口接受切片/迭代器和调用者提供输出缓冲，支持 Rayon 可选并行。
- **X-PERF-004** 大型历表和星表支持流式或内存映射，不复制整个文件。
- **X-PERF-005** 缓存键必须包含时刻、模型、数据版本、目标、中心和参考系，避免跨上下文污染。

### 6.9.6 安全与鲁棒性

- **X-SAFE-001** 解析不可信星表和 BSP 文件时检查长度、偏移、整数溢出、非有限值和资源上限。
- **X-SAFE-002** `unsafe` 仅允许出现在隔离适配器内，并以安全不变量和测试证明包围。
- **X-SAFE-003** FFI 后端必须把上游全局状态、线程安全和错误栈封装在明确同步策略后。
- **X-SAFE-004** 核心计算不得 panic；panic 仅限程序员违反不可构造的不变量。
- **X-SAFE-005** 所有外推、近似和截断必须由调用者通过命名入口或显式策略选择。

## 7. 接口体验要求

### 7.1 构造与转换

- 合法值使用短构造器，例如 `Angle::deg(12.3)`、`Date::new(2026, 8, 5)`。
- 可能失败的构造返回 `Result`；范围在类型内可规范化时提供命名构造器，例如 `Lon::wrap`。
- 单位读取使用短方法，例如 `.rad()`、`.deg()`、`.arcsec()`；不得用 `as_f64()` 隐藏单位。
- 时间尺度转换经 `TimeContext` 完成；参考系转换经 `Frames` 或具体变换完成。
- 公开接口优先对象方法、关联构造器和工作流对象；自由函数只允许用于无法自然归属且不会形成浅模块的基础运算。

### 7.2 结果层级

每个高层观测结果应提供：

1. 最常用主值；
2. 明确的参考系、原点、时间尺度和是否含折射；
3. 算法需要公开时提供数值诊断；
4. 到低层强类型量的无损访问。

### 7.3 错误

错误至少按以下类别稳定区分：

- 非法输入和范围；
- 时间表示不存在/歧义；
- 数据缺失、过期或覆盖外；
- 目标/参考系/段类型不支持；
- 退化几何；
- 数值不收敛；
- 解析格式损坏；
- FFI/后端失败；
- 请求精度无法由当前模型保证。

错误必须携带相关字段、时刻/区间、后端和可恢复建议，不把上游整数状态码直接暴露给普通用户。

## 8. 数据与模型治理

- 所有闰秒、EOP、历表、常数、IAU/IERS 模型和星表适配器必须记录来源 URL、发布版本、获取时间、校验和与覆盖区间。
- 内置数据必须有明确更新流程和版本变更记录；库升级不得悄悄改变历史结果。
- 用户可以固定数据快照以获得可复现结果。
- 预报 EOP 与最终 EOP 必须可区分；结果应允许拒绝预报数据。
- DE440、DE441、VSOP87 等后端的精度声明只引用上游资料，不从少量回归样本外推。
- 许可证不兼容或名称使用受限的上游代码不得直接复制进核心；通过依赖/适配器使用也必须完成许可证审查。

## 9. 非功能需求

### 9.1 正确性

- 每个标准算法必须注明规范、模型版本、公式来源和适用区间。
- 与 SOFA/ERFA 对应的实现必须逐例通过其官方验证向量，并增加边界和往返测试。
- 历表后端必须与生产者参考工具在覆盖端点、段重叠和随机样本上差分验证。
- 任何近似模型必须在文档中给出适用范围和已验证误差上界。

### 9.2 精度

- 日历和整数日转换在支持范围内必须精确可逆。
- 两段式时间算法不得无必要损失低段精度；相邻纳秒级增量在声明范围内可区分。
- 基础旋转应保持正交和行列式 `+1`；往返角误差目标不高于数个 `f64` 舍入单位或上游模型误差。
- SOFA/ERFA 算法的数值差异不得超过其测试向量容差，除非文档记录更严格或不同的算法依据。
- 历表、折射和事件的精度由后端和模型决定；接口必须传递而非夸大精度。

### 9.3 性能

- 单次基础量运算不得分配。
- 单次参考系旋转不得分配。
- 已加载 SPK 的单目标单时刻求值不得分配，错误路径除外。
- 批量星表传播不得要求为每条记录创建堆对象。
- 发布前建立基准：角度/向量、时间转换、IAU 变换、SPK 求值、星表批处理和事件搜索。

### 9.4 可移植性

- 稳定 Rust；MSRV 在发布策略中固定并测试。
- 支持主流 Linux、macOS、Windows 的 64 位目标。
- 数学内核支持 `no_std` 的目标不得依赖 libc 时间、文件系统或线程局部全局状态。
- WASM 支持不要求 FFI 后端；纯 Rust 后端应可独立启用。

### 9.5 可维护性

- 公开类型和方法必须有语义文档、单位、范围、模型、错误与示例。
- 不建立多个表达同一概念的平行类型体系。
- 上游适配器与领域接口隔离；替换底层库不影响领域模型。
- 依赖默认关闭非必要特性，避免把网络、异步运行时或大数据嵌入核心。

## 10. 验证与验收

### 10.1 测试层级

1. **单元测试**：不变量、边界、退化输入、已知公式和结构化错误。
2. **标准向量测试**：SOFA/ERFA、IERS、NAIF/JPL、Gaia 文档和历表生产者提供的权威样例。
3. **差分测试**：与至少一个独立参考实现比较随机和边界样本。
4. **性质测试**：旋转往返、时间往返、坐标往返、球面不变量、事件括根不变量。
5. **集成测试**：真实闰秒/EOP/DE BSP/Gaia 小样本的端到端工作流。
6. **回归测试**：每个已修复缺陷保留最小可复现输入。
7. **基准测试**：热路径吞吐、延迟、分配数和大文件访问。

### 10.2 P0 退出条件

- 所有 P0 类型无法构造非法状态，或非法状态只能通过返回错误的构造器进入。
- UTC→TAI→TT、UTC→UT1、TT↔TDB 的支持范围和数据依赖有端到端测试。
- GCRS→CIRS→TIRS→ITRS 与 SOFA/ERFA 权威结果一致。
- Gaia 六参数记录可传播并生成强类型站心观测位置。
- DE BSP 后端能查询太阳、地球、月球及主要行星状态，覆盖和段优先级正确。
- 升中落与基本月相事件在真实历表和站点场景中通过独立参考结果验证。
- 公开接口没有无单位时间、无尺度 JD、无参考系状态和无方向旋转。

### 10.3 P1 退出条件

- Gaia DR3 流式解析、协方差传播和批处理达到声明的内存/性能目标。
- VSOP87 与 DE 后端可在同一接口替换，各后端的精度范围有明确文档。
- BJD_TDB 和 barycentric radial-velocity correction 通过权威样例。
- 折射和地平事件覆盖极区、近地平线、多根和无根场景。
- 事件引擎在切触根、跨 `0/2π`、覆盖端点和多个事件场景中不漏报。

### 10.4 P2 退出条件

- 日月食和掩星返回完整接触序列、分类、局部可见性和误差信息。
- SPICE 姿态、PCK/CK 或等价后端通过覆盖和参考系交叉验证。
- SGP4/TLE、MPC 小天体和数值传播适配器保持参考系与时间语义完整。
- 对流层、电离层和站点位移模型各自通过来源机构样例。

## 11. 明确非目标

- 不把 hyastro 变成 GUI、在线星表服务或自动下载器。
- 不在核心中维护未经权威来源审核的全天体名称数据库。
- 不承诺单一模型在古代到遥远未来保持同一精度。
- 不把任务设计、轨道优化、滤波定轨等完整航天动力学产品复制进基础天文库；这些能力通过独立动力学接缝接入。
- 不复制 SOFA/ERFA/NOVAS 全部自由函数形成一对一上层镜像。
- 不用低精度解析算法冒充 DE/SPK 高精度历表。
